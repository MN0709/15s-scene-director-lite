# 15秒剧情镜头导演 · 基础版（short-scene-director-lite）

一个把「简单剧情 / 参考图 / 简短想法」整理成**最长 15 秒、动作连续、电影感**中文视频生成提示词的 Doubao Skill。

一句话用法：把你想拍的剧情丢给它，它给你一份「能直接扔进视频工具出片」的提示词，动作不翻车、人物不崩、有电影感。

## 它能做什么

- 文生视频、图生视频提示词整理
- 一镜到底、两至三个镜头的镜头设计
- 动作时间线、运镜、光影色调、声音设计
- 局部修改已有提示词
- 极简输入：一句话想法也能直接补全成可用提示词

## 它不做什么

不用于完整剧本、长篇分镜、整部短剧、广告策划、角色设定、复杂世界观开发。它只处理「一个核心事件、15 秒内发生完」的最小剧情单元。

## 核心方法论

1. **剧情压缩公式**：`初始状态 → 触发动作 → 可见变化 → 明确结果`，只保留一个核心事件。
2. **动作预算控制**：每个时间段只安排一个主要人物动作 + 一种主要运镜，稳定性优先于动作数量。
3. **镜头形式**：默认一镜到底，只有观察角度必须改变时才用两至三个镜头。
4. **摄影/光影/声音统一设计**：镜头系统、光源方向、色调分布、环境音与动作音全部写清，不堆形容词。
5. **四段式固定输出**：

```text
【画面与人物前提】
【动作与镜头时间线】
【光影、色调与成像约束】
【声音与对白】
```

## 安装方法（豆包工作台）

1. 下载本仓库：点击右上角 **Code → Download ZIP**，或直接下载打包好的 [short-scene-director-lite.zip](./short-scene-director-lite.zip)。
2. 解压后得到 `short-scene-director-lite` 文件夹（里面是 `SKILL.md` 和 `agents/`）。
3. 把该文件夹放进豆包工作台的 skills 目录（Windows / macOS 均可按豆包官方 skill 安装流程导入，或放入工作区 `.skills` / `.user_skills` 目录）。
4. 刷新/重启豆包后，直接对豆包说：

> 「使用 short-scene-director-lite 将我的简单剧情整理成最长 15 秒、动作连续的中文视频提示词。」

## 目录结构

```text
short-scene-director-lite/

└── agents/
    └── openai.yaml     # agent 配置（显示名、默认提示词）
```
